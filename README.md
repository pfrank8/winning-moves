# Winning Moves

A game theory playground for a young mathematician. Twenty-one chapters, each
with a real idea, a game to play against a robot that never makes mistakes,
and the mathematics underneath.

Build: `python3 build.py --check`. Output lands in `docs/`, which GitHub Pages serves.

See `CLAUDE.md` for the project layout and `CHAPTER_SPEC.md` for how chapters are written.
